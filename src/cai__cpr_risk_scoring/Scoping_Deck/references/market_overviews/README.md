# Prior-auditor Market Overview references

Drop the **8 prior auditors' Market Overview slide texts** here — one file per auditor
(`.txt` or `.md`). File names don't matter; they're read in sorted order.

These are used only as **style / structure / wording guidance** for generating the current
audit's Market Overview. Their facts are NOT treated as facts about the current audit.

Alternative: paste the texts into `INLINE_MARKET_OVERVIEWS` in
`scoping_deck/src/references.py` instead of using files.
