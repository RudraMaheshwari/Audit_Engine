# Prior CPR Assessment — Findings from previous CPR (IM Cambodia, 2021)

## Company Organized Events
- Post Event Documentation and Reconciliation: did not obtain vendor supporting documentation during the post-event reconciliation process, and did not compare actual vs budgeted costs.
- HCP/GO Classification: did not assess HCP/GOs' level of influence when determining whether transactions require HCCO approval prior to execution.

## Congresses
- Selection Criteria: did not document the selection criteria for an HCP that attended a Hematology event.
- Post Event Documentation: did not obtain vendor supporting documentation during post-event reconciliation.
- HCP/GO Classification: did not assess HCP/GOs' level of influence for HCCO approval.

## Fee for Service ("FFS")
- Tax Deductions: did not deduct withholding taxes from some FFS payments; withholding tax coding was incorrectly set up for some HCPs.
- HCP/GO Classification: did not assess HCP/GOs' level of influence for HCCO approval.

## Patient Support Programs ("PSP")
- Fair Market Value ("FMV"): did not conduct an appropriate FMV assessment, unable to demonstrate reasonableness of TPI compensation.
- Contract Terms: agreements did not outline patient eligibility criteria; no documentation that service fees invoiced by TPIs matched the agreed fee schedule.
- GL Account: recorded all PSP transactions to an incorrect GL account.
